我的图书馆sumatralib: AI版

在sumatralib现有版本基础上，在阅读区右侧增加一个AI工作区。为了加入AI大模型功能，需要在菜单中添加AI模型设置。

1 AI模型设置

在设置菜单中添加AI模型设置：菜单>设置>AI模型。用户点击后出现对话框，设置AI大模型的调用网址、模型名称和apikey. 对话框结构如下：
---------------------------------------
       设置AI大模型
API地址： ___________________________
API Key： ___________________________
模型名称：___________________________
            测试键         确定键
---------------------------------------

当信息尚未填入完整，测试键呈现灰色不可用状态。当信息填入完整，测试键恢复正常，可以点击。

当用户点击测试键，并且测试成功，那么显示连接成功，同时确定键从灰色不可用状态恢复正常，可以点击。当用户点击确定键，那么完成，模型设置对话框消失。 


2 AI工作区的位置如下：
| 我的图书馆 | 书签          |       阅读区                         |  AI工作区   |

AI工作区的结构如下：
--------------------------------
            AI工作区
  ---------------------------
  |                                          | 
  |         文本框                      | 
  |                                          | 
  |                                          | 
  ---------------------------
                     确定键
--------------------------------
            AI 回复区





--------------------------------

用户在文本框输入对AI模型的prompt.

如果没有设置AI模型，或者AI工作区中的文本框空白，那么确定键处于灰色不可用状态。

当用户点击确定键，将文本框内的prompt发送给大模型，大模型的回复展示在AI回复区。

3 阅读区的左键松开菜单

在阅读区域，用鼠标左键highlight一段文字，松开左键后，跳出一个菜单：Explain briefly 、Explain in
  depth（中文版：简要解读、深入解读）。如果用户选择简要解读，那么prompt AI "Please briefly explain: highlighted text"
  （中文版：请简要解读highlighted text）. 如果用户选择深入解读，那么prompt AI "Please explain in depth: highlighted
  text"（中文版：请深入解读highlighted text）.
