我的图书馆sumatralib: AI+notes

在sumatralib现有版本基础上，在AI工作区增加记笔记的功能。

1. AI工作区的结构修改如下：
--------------------------------
            AI辅助
  ---------------------------
  |                                    | 
  |         文本框                 | 
  |                                    | 
  |                                    | 
  ---------------------------
           记笔记       问AI
--------------------------------
            AI 回复区





--------------------------------

用户在文本框输入笔记，或者从阅读区拷贝文字，黏贴到文本框，点击“记笔记”按钮。程序做如下反应：

    （a）程序在当前目录寻找跟当前阅读区书籍相同文件名的md文件。比如如果书籍的文件名为 Thinking Fast Slow.pdf, 那么笔记文件为Thinking Fast Slow.md.
	（1）如果没有相应的md文件，创建新的笔记文件，书籍文件名.md, 并在该文件中写入第一条笔记。
	（2）如果有相应的md文件，那么在该文件中添加一条笔记。
    （b）每一条笔记的内容为：文本框内容+书籍页码+日期和时间。文本框第一行默认为标题，加粗。



3 阅读区的左键松开菜单，修改如下：

阅读区域，左键选定一段文字后跳出的菜单中添加：记笔记（Take notes）。如果用户点击该选项，那么选定的文字出现在AI工作区的文本框内，用户可以做进一步编辑。
